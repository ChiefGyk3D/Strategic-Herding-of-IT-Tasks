# Sister projects: SHIT and SAFO

- SHIT (this repository) and SAFO (ChiefGyk3D/scrum-around-and-find-out, public) are sister projects. They are at parity on base features: issue and board discipline, local-first model use, review and merge gates, measurement before cutting, token savings.
- They differ in application. SAFO is the maintainer's own custom setup (his boards, tools, machines and guard files). SHIT is the portable edition for an enterprise setting: coworkers, any AI tool or none, an optional local Ollama, everything configurable.
- When a fix, measurement, tool or idea lands here, say in the same response whether it belongs in SAFO and file or link the issue there. A SAFO improvement comes into SHIT only as a configurable port: never hard-code the maintainer's GPUs, ports, hostnames, vendors, boards or accounts. A SAFO-only item says why.
- Never copy private details between the two, and keep this repository's private details out of SAFO's public text.
- Owner order, 2026-11-27 (issue 41).
